# Сверка строительных документов

Проект для хакатона AI Founders Sprint (Кыргызстан). Сервис сверяет строительные документы между собой: ведомость объёмов работ (ВОР), смету, договор и акты выполненных работ. Он приводит файлы к единой таблице, сопоставляет позиции и показывает **возможные расхождения**, каждое со ссылкой на файл, лист и строку.

> **Данные синтетические.** Структура документов взята с публичных тендерных документов, цены в сомах ориентировочные, не рыночные. Для работы у клиента нужны его документы. Система сверяет документы между собой и **не доказывает** фактическое выполнение работ; окончательное решение за специалистом.

## Что это решает

ВОР, смета, договор и акты приходят в разных форматах и сверяются вручную в Excel или PDF. Завышение объёма или цены легко пропустить до оплаты. Целевые пользователи: технадзор, сметчики, заказчики строек, инжиниринговые компании.

## Принцип

**ИИ читает документы, обычный код считает.** Сравнение, арифметика, сопоставление и правила это детерминированный Python (pandas): одинаковый вход даёт одинаковый результат. LLM (Gemini) необязательный слой для спорных пар названий и пояснений, с кэшем и запасным режимом. Приложение обязано работать без LLM и показывать, что оно в базовом режиме.
